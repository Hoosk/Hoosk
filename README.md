# Oscar · Hoosk

> "I've been writing code for longer than I can remember."

That's been my GitHub bio for years, and it keeps getting truer. Started in the PHP/Laravel era, took the scenic route through a few more languages, and now I split my time between **Go** for the parts that must not fall over, **TypeScript/React** for the parts that must look like they don't fall over, and **Postgres** for the parts that must remember things. SQLite shows up too — for local tools and quick experiments, where it is honestly unbeatable.

Self-hosted and local-first by default: if a service can run on my own hardware, it usually already does.

## In the lab

Most of my current work lives in private repos while it grows up: self-hosted infrastructure tooling, an AI-assisted mortgage comparator for the Spanish market, and a few learning experiments that refuse to stay experiments. When they're presentable, they move to the window.

## The homelab

The kind of developer who reads "cloud" as "someone else's computer" and takes it personally:

- **Pi-hole on a Raspberry Pi Zero 2 W** — DNS for the whole house; every ad dies on a board the size of a matchbox.
- **Home Assistant on a Raspberry Pi 3B+** — the house is smart now; whether it's obedient is another matter.
- **A NAS running Docker** — where everything else lives.
- **Two phones running Kubernetes on postmarketOS** — experiments kept alive purely for the pleasure of seeing them work. The cluster fits in two pockets.
- **Local LLMs** with Ollama, llama.cpp and LM Studio — some prompts don't need to leave the house.

## Trivia

- Backend-first by conviction, frontend by necessity.
- My first programs were tic-tac-toe in C for a class assignment and an Android app that displayed cat pictures. Peak software, honestly.
- I wrote a whole signals library to dodge React re-renders, then [wrote a blog post about it](https://mediopixel.net/posts/esquivando-rerenders-react-signals/) anyway.
- Every side project has a beginning, some have a middle, and a select few have an end. The ratio improves yearly.
- I can tell you exactly which project each good idea died in. I keep them as monuments.
- It's not paranoia if the uptime dashboard agrees with you.
